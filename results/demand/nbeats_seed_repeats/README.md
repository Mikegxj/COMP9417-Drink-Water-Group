# N-BEATSx 三种子跨年稳定性复核

固定已选配置：10 天历史、宽度 128、天气/日历输入、学习率 0.001、59 轮。保持原训练窗口和五次重训日期，每次重新初始化使用同一实验种子。种子 42 复用原预测，43、44 在相同本机 CPU 环境补跑。

本轮报告所有预先指定种子，不按历史成绩挑选种子，也不做预测集成。MAPE 单位为 %；均值是三个独立运行的 MAPE 均值，不是平均预测的 MAPE。种子标准差为三个结果的样本标准差，单位为百分点，不是未来预测误差的置信区间。
