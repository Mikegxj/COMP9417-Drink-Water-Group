# 误差分析与等权集成

本轮只分析已保存的半小时预测，不重训、不搜索权重。集成预测 = 0.5 × N-BEATSx + 0.5 × LightGBM；冻结版和定期重训版各自配对，使用完全相同的日期和真实值。所有 MAPE 单位为 %。

这些历史结果已经参与方案探索，属于事后诊断；近期段为 2025 年至 2026 年 10 月。

## 主要发现

- **定期重训等权集成有效**：全期 MAPE 3.076%，相对较好的单模型降低 0.369 个百分点；近期为 4.063%。
- **改善跨越多个时期**：全期 142 个月中 121 个月同时优于两个组成模型；近期为 20/22 个月。
- **冻结版集成没有超过较好的组成模型**：全期 5.084%，LightGBM 为 4.426%。不能把定期重训的集成收益推广到冻结版。
- **近期最难的时段集中在中午**：集成在 12:30 开始的半小时 MAPE 达 10.062%，MAE 564.0 MW，平均偏差 +156.6 MW，存在整体高估。
- **高温误差大，但并非总误差的主要来源**：近期 ≥30°C 时 MAPE 9.670%，仅 438 个半小时，贡献 3.25% 的绝对百分比误差总和；20–30°C 组贡献 47.86%。
- **近期周末较难**：集成周末 MAPE 4.467%，周一至周五 3.901%。

下一步优先检验中午负荷形状、天气/辐射相关特征及训练窗口是否改善这些误差；当前分组不能单独证明太阳能或某个天气变量是原因。多种子复核应保留当前固定权重，避免同时改变多个因素。

## 互补性与局限

complementarity.csv 包含有符号 MW 误差相关系数、误差方向相反的比例，以及集成相对单模型的 MAPE 差值。差值区间使用配对 7 日循环区块 bootstrap，1,000 次抽样；未消除跨年非平稳性或事后选择偏差，只作描述性参考。

grouped_errors.csv 同时记录样本数、样本占比、MAPE、MAE、平均有符号误差（预测−实际）、绝对百分比误差总和占比。高 MAPE 的小样本组不一定贡献最多总误差。
