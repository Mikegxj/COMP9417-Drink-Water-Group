## 实现对应关系

| 已有结果中的名字 | 实际实现 | 后续使用边界 |
|---|---|---|
| GAM | 每个半小时时段独立的样条变换与 Ridge 加性回归。天气平滑项使用固定五节点，负荷滞后用线性项。 | 对应加性模型思路。尚需搜索样条复杂度和正则化强度。 |
| LightGBM | 官方库 LGBMRegressor，350 棵树、学习率 0.04、31 个叶子。 | 已搜索少量特征变体，树复杂度与训练目标仍需调参。 |
| N-BEATS | 三个独立通用基函数残差块，每块两个 128 单元隐藏层，同时输出 backcast 与 forecast。 | 可称紧凑通用 N-BEATS，容量和历史窗口尚未搜索。 |
| N-BEATSx | 通用 N-BEATS 之外单独添加一个外部变量预测头，系数由历史及未来变量生成。 | 统一描述为“自定义外部变量版 N-BEATS”。论文 NBEATSx 将外部变量整合到块结构，当前结果不足以代表论文实现。 |
| TFT | 单头注意力、历史/未来 LSTM、简化未来变量选择、门控归一化及前馈输出。 | 描述为“简化 TFT-inspired 网络”。原论文的 GRN 变量变换、静态上下文与 enrichment、可解释注意力等尚未完整对应。 |
| TCN | 八层残差因果膨胀卷积，通道 16。历史末端表示加上昨日/上周同期负荷与目标日变量。 | 感受野为 511 点，可覆盖当前 336 点窗口。若使用 912 点窗口，须同步扩展感受野。 |
| LSTM | 单层 16 单元编码器，预测头同时接收昨日/上周同期负荷及目标日变量。 | 属于带显式滞后捷径的 LSTM。需搜索隐藏宽度、层数和窗口。 |

因此，旧结果文件中的 nbeats/calendar_temp 与 tft 分别是上述自定义模型及简化模型。后续新结果使用明确的 architecture 字段。原始配置和预测保留供复核。

参考依据来自 [NBEATSx 原论文](https://arxiv.org/abs/2104.05522)、[作者维护的 NBEATSx 实现](https://github.com/Nixtla/neuralforecast/blob/main/neuralforecast/models/nbeatsx.py) 与 [TFT 原论文](https://doi.org/10.1016/j.ijforecast.2021.03.012)。

## 时间边界审查

使用真实数据进行六项回归检查，包括改变验证期目标后训练输入与缩放不变、闰日及午夜对齐、表格离线特征与逐日可用信息构造一致、滚动窗口缩放仅使用训练期、卷积因果性、五种神经结构输出形状和有限梯度。六项检查通过。

序列训练一天一个样本，最初七天用于输入上下文。2010–2013 年有 1,454 个训练日样本。各模型均在 2014 年的 365 天验证，每天输出 48 点。葡萄牙对照论文的训练使用逐小时滑动窗口，当前实现每个市场日取一个训练窗口，样本构造方式也有差异。[论文训练协议](https://arxiv.org/html/2302.12168v2)

LSTM/TCN 输入包含额外显式滞后捷径，模型间存在输入表示差异。GAM、树模型输入前一天同期温度，当前神经模型的历史输入仅为负荷，需在后续控制实验中记录这些差别。

复现检查可运行 `python -m unittest experiments.demand.screen.test_forecast_boundaries`。

## 收敛实验协议

保留原始架构、336 点窗口、MAE 训练目标、Adam 学习率 0.002、batch size 32。唯一主要训练变动是从固定 16 轮改为上限 120 轮，并在验证 MAPE 连续 20 轮没有改善时停止。每轮记录训练及验证 MAE/MAPE，保存并恢复验证表现最好的权重。以 2010–2013 年训练，2014 年只用于选轮数；未访问后续年份的目标来选择 checkpoint。

简化 TFT 在 120 轮上限附近仍改善，追加相同种子、240 轮上限的运行。所有额外验证搜索均记录在扩展目录。

第一轮使用种子 42，对纯负荷 N-BEATS、自定义外部变量版、简化 TFT、TCN 和 LSTM 都执行。追加种子 43、44 复核两种 N-BEATS 结构。这些验证成绩包含最佳轮数选择的收益，仍需后续时间段评估。

```sh
python -m experiments.demand.convergence.check_convergence
python -m experiments.demand.convergence.check_convergence --models nbeats nbeats_exogenous --seeds 43 44 --output results/demand/convergence_repeats
```

每个 case/seed 目录保存 curve.csv、best.pt、summary.json 和 2014 年逐点预测。summary 中记录停止原因、轮数、结构描述、种子及源文件校验和。best.pt 供本实验加载，预处理需按训练数据重建。

## 下一轮搜索预算

预算先按独立配置数管理，同时记录每次训练时间。表格模型以 12 个配置为起点，覆盖 GAM 的样条节点与正则化、M5′ 的深度与最小叶样本、LightGBM 的叶数/最小叶样本/学习率。神经网络每种先 8 个配置，覆盖历史窗口、容量和学习率，并用早停选择轮数。各模型前两名再用三个固定种子复核，报告均值与标准差。CPU 实测时间足以安排当前收敛检查；在确认正式 TFT、NBEATSx 实现之后再估算 Katana 是否能缩短总耗时。

比较时固定每个模型的特征版本，先解决结构和训练预算，再分开追加天气消融。完整架构、更多滑动训练窗口及更大的模型都需要重新测量训练时间。

## 实测收敛结果

种子 42、相同结构和优化器下，第 16 轮与恢复最佳权重后的验证成绩如下。全部运行最终满足连续 20 轮无新最佳值的早停条件。

| 实现 | 第 16 轮 MAPE | 最佳轮 MAPE | 最佳轮数 | 实际停止轮数 |
|---|---:|---:|---:|---:|
| 简化 TFT-inspired | 2.779% | 2.190% | 129 | 149 |
| 自定义外部变量版 N-BEATS | 2.507% | 2.273% | 33 | 53 |
| LSTM | 2.765% | 2.292% | 112 | 132 |
| TCN | 2.847% | 2.362% | 70 | 90 |
| 紧凑纯负荷 N-BEATS | 2.776% | 2.536% | 44 | 64 |

外部变量版在三个种子下的验证 MAPE 均值为 2.281%，样本标准差 0.008 个百分点，范围 2.273%–2.290%。TFT、TCN、LSTM 此轮各一个种子。

原 LightGBM 特征搜索后的验证 MAPE 为 2.483%。延长训练改变了初筛顺序。当前结果反映轮数选择的作用，尚未完成各模型超参数搜索，也未用这些新 checkpoint 的配置重新跑历史模拟。

当前紧凑模型在本机的单次收敛运行约为 N-BEATS 5–10 秒、TCN/LSTM 约 3 分钟、简化 TFT 约 5 分钟，部分测量发生在并行运行期间。正式架构与训练样本窗口变化后需重新计时。
